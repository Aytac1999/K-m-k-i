# Gömrük Köməkçisi (v0.2, sınaq versiyası)

## Quraşdırma
1. Chrome → `chrome://extensions` → sağ yuxarıda "Developer mode" aç.
2. "Load unpacked" → bu qovluğu (manifest.json olan) seç.
3. Alətlər panelindəki extension ikonuna basın, yan panel açılır.

## İstifadə
1. e.customs.gov.az saytına ASAN imza ilə özünüz daxil olun, "Gömrük bəyannaməsi" xidmətini açın.
2. Yan paneldə tarix aralığını, növü və nəyin yüklənəcəyini seçin, "Başla" basın.
3. Fayllar Downloads içində seçdiyiniz qovluqda saxlanılır.

## Adlandırma
- `2024-12-28_01241000538425.adoc` – orijinal
- `2024-12-28_01241000538425_1.pdf`, `_2.pdf` … – .adoc içindəki PDF-lər ayrı-ayrı
- `2024-12-28_01241000538425.pdf` – birləşdirilmiş tək PDF
- `01241000538425 əlavə sənədlər 1.pdf`, `… invoys 1.pdf`, `… CMR 1.pdf`
